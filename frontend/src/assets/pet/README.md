# Default pet model

`default.vrm` is **AvatarSample_C**, one of the official VRoid (pixiv) sample
avatars, obtained from the community mirror
[madin/vrm-samples](https://github.com/madjin/vrm-samples) (`vroid/stable/AvatarSample_C.vrm`).

Per the VRoid sample-model terms the copyright is retained by VRoid Project /
pixiv and is **not** waived; alteration and redistribution are permitted under
those terms. Keep this credit file alongside the model. The model's embedded
VRM meta block carries its full license conditions.

- Source: <https://github.com/madjin/vrm-samples/blob/master/vroid/stable/AvatarSample_C.vrm>
- Official model page: <https://hub.vroid.com/characters/2843975675147313744/models/5644550979324015604>
- Size: 13,132,268 bytes

User-uploaded models (Settings → Desktop pet → 管理模型) are stored server-side
under `<data_dir>/pet-models/` and are the uploader's responsibility.
